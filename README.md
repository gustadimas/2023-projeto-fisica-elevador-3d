# Projeto de Física: elevador 3D

Projeto da faculdade, de dez/2023. Subi pro GitHub em novembro de 2026 só pra guardar, sem mexer no código.

Projeto final de física em 3D. Um personagem animado entra num elevador, as portas são animadas quando ele entra (`Door.cs`) e, quando você aperta espaço, o elevador sobe com aceleração constante. A posição é calculada pela fórmula s = v0*t + a*t²/2 no `Aceleracao.cs`.

## Como abrir

Abra a pasta do repositório pelo Unity Hub (Add project from disk). Usei o Unity 2021.3.18f1. A pasta Library não está no repositório; o Unity gera de novo na primeira vez que abre.

## Créditos

O personagem e as animações são do Mixamo (cada FBX tem uns 54 MB). Outros assets estão em `Assets/AssetsTerceiros`.
